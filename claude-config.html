Claude 設定アシスタント

Claude / Claude Code の設定をフォームから組み立て。生成されたものをコピーして該当ファイルに貼るだけで使えます

使い方: 下のタブで作りたいものを選び、左で項目を埋めると右に内容が生成されます。「コピー」もしくは「ダウンロード」ボタンで取得 → 該当ファイルに貼り付けて完成。
ファイルの場所：~/.claude/settings.json（全体設定） / CLAUDE.md（プロジェクト直下） / ~/.claude/commands/<name>.md（スラッシュコマンド） / ~/.claude/agents/<name>.md（サブエージェント）

⚙️ settings.json を組み立て

Claude Code 全体の挙動を決める設定ファイル。~/.claude/settings.json に保存します。

🟢 許可するアクション
クリックでON/OFF。チェックしたものは確認なしで実行できます。
書式例: Bash(npm:*) / Read / WebFetch(domain:example.com)
🔴 禁止するアクション
許可よりも優先されます。危険なコマンドはここで止めます。
🪝 フック（イベントで自動実行）
例: Edit/Write 後に npx prettier --write を自動実行 など。
🌍 環境変数
🎨 その他

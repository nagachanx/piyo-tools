👋 Claude Code とは？

そもそも何ができるのか、簡単な確認から始めます

Claude Code は、ターミナル（Macの「ターミナル」アプリ／Windowsの「コマンドプロンプト」）から使えるAI助手です。下のようなことを あなたのパソコン上のファイルに対して 直接お願いできます:

  • 長い文章・PDF・コードを読んでもらい、要約・翻訳・校正してもらう
  • 「このフォルダを整理して」と頼んで実際にファイルを動かしてもらう
  • 「READMEを書いて」「メールを下書きして」「Excelの数式を作って」など
  • 難しい用語の解説や、操作方法を一緒に進めてもらう

必要なもの

  • インターネット接続のあるパソコン（Mac / Windows / Linux）
  • 30分程度の時間（初回のインストールと設定で）
  • 会社の Claude アカウント（チームプランで全スタッフに発行済み。メールアドレスやパスワードが分からない場合は社内のIT担当・上長に確認してください）
専門用語は出てきますが、わからなくても そのままコピー&ペーストするだけ で進められるようにしています。

💬 もう一つの始め方: Claudeチャットに聞きながら進める

「画面を見ながら案内してほしい」「コマンドが出てきて固まった」など、本当に初めての方はこのページを順に進めるより、claude.ai のチャットに直接相談しながら進める方が早いこともあります:

  1. claude.ai を開いて会社アカウントでログイン
  2. こう聞いてみる:
    Claude Code を Mac にインストールしたいです。最初から1つずつ案内してください。専門用語は使わず、画面のスクショを送るので確認しながら進めたいです。
  3. 画面のスクリーンショットを撮ってチャットに ドラッグ&ドロップ で添付 → 「これでOK？」「次は何をすればいい？」と聞く
  4. エラーが出たらメッセージをコピペして「これどうすれば？」と相談
スクショの撮り方: Mac は ⌘ + Shift + 4、Windows は Win + Shift + S で範囲選択して撮影できます。

このページの手順をやりつつ、つまずいたら Claude チャットに聞く、というハイブリッドが一番おすすめです。

📦 Node.js（ノードジェイエス）をインストール

Claude Codeを動かすために必要な土台ソフトです（無料）

  1. 公式サイト nodejs.org/ja を開く
  2. 緑色の 「LTS（推奨版）」 ボタンをクリックしてダウンロード
  3. ダウンロードした .pkg ファイルをダブルクリック → 画面の指示に従って「続ける」を押していくだけ
  4. インストールが終わったら、ターミナルを開きます（Spotlight検索で「ターミナル」と入力）
  5. 下のコマンドを貼り付けて Enter:
$node --version
v20.x.x や v22.x.x のような表示が出ればOK

  2. 緑色の 「LTS（推奨版）」 ボタンをクリックしてダウンロード

$nvm install --lts

STEP 4 / 8

🤖 Claude Code をインストール

先ほどの Node.js を使って Claude Code 本体を入れます

同じターミナル（または PowerShell）で、下のコマンドを実行してください:

$npm install -g @anthropic-ai/claude-code

少し時間がかかります（30秒～2分程度）。完了したら確認:

$claude --version
バージョン番号が表示されればインストール完了
EACCES: permission denied のようなエラーが出る場合は、コマンドの前に sudo を付けて再実行（Macのログインパスワードを聞かれます）:
sudo npm install -g @anthropic-ai/claude-code
Windowsで「実行ポリシー」エラーが出たら、PowerShellで Set-ExecutionPolicy -Scope CurrentUser RemoteSigned を実行してから再試行。
nvm 経由で Node.js を入れた場合は sudo 不要です。

STEP 5 / 8

🔑 会社の Claude アカウントでログイン

特別な準備は不要。次の STEP 6 で claude を起動するとログイン画面が出ます

会社のチームプランで全スタッフに Claude アカウントが発行されています。Claude Code 初回起動時のログインフローは以下の通り:

  1. STEP 6 で claude コマンドを実行すると、ターミナルに ログイン用URL が表示されます
  2. そのURLをブラウザで開く（自動でブラウザが起動することも）
  3. 会社アカウントのメールアドレスで claude.ai にログイン
  4. 表示される「Authorize（承認）」ボタンをクリック
  5. ターミナルに戻ると Claude Code の準備完了画面が表示されます
このステップでは事前に何かをやる必要はありません。STEP 6 で実際に claude を起動する時にログイン画面が出る、と覚えておくだけでOK。

会社アカウントが分からない場合

  • メールアドレス・パスワードが分からない → 社内のIT担当または上長に確認
  • 「招待メールが届いてない」「自分のアカウントがあるか不明」も同様に確認

（参考）個人で別アカウント・API キーを使いたい場合

クリックで展開

会社アカウントではなく、個人プロジェクトや学習用に自前で従量課金で使いたい場合（中・上級者向け）:

  1. console.anthropic.com でSign up、クレジットカードで残高チャージ
  2. 「API Keys」→「Create Key」で sk-ant-... を発行
  3. 環境変数 ANTHROPIC_API_KEY に設定（OS別の方法は「Claude 設定アシスタント」を参照）
API キーはパスワードと同じ。共有・公開しないこと。
